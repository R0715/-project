# 算法与电机接口

白杨负责电机接口、烧录和驱动联调。当前已发布供循迹与避障代码对接的接口草案，待小组确认。固件实现、烧录、左右轮转向和编码器计数极性待实测。

## 上层调用

| 函数 | 约定 |
| --- | --- |
| `Motor_Init()` | 初始化电机输出和编码器，默认停车。 |
| `Motor_SetPWM(left, right)` | 左右轮命令以 PWM 千分比表示，范围 −1000 到 1000。正数表示该轮向车头方向驱动车体，负数倒转，0 请求停止。超出范围时限幅。 |
| `Motor_Stop()` | 同时请求两轮停止。制动或滑行方式待驱动联调验证。 |
| `Encoder_GetCounts(&left, &right)` | 读取左右轮有符号累计计数，向前为正，读取后保留累计值。速度环用相邻两次读数的差计算采样周期内的增量。 |

接口声明见 [motor.h](motor.h)。上层可以先按这些函数名和参数编写调用，连接成可运行固件还需要对应实现。

## R08 接线依据

- J5 电机控制依次为 PA8、PA0、PA1、PA11、GND。
- J6 编码器的 E1A/E1B 对应 PA6/PA7，E2A/E2B 对应 PB6/PB7。第 5 脚为 GND，第 6 脚留空。
- 核心板引出了 SWD，首次联调计划用 ST-LINK。Type-C 烧录待确认实际核心板版本和启动方式。
